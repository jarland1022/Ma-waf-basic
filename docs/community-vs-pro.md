# 社区版与专业版

社区版放在 GitHub 上，让人能在自己的机器上看到拦截效果。专业版卖的是规模化运维和有人负责，不是再卖一套「能挡住 SQLi」的规则。

## 定价

| 项目 | 建议 |
|------|------|
| 社区版 | 免费，Apache-2.0 |
| 专业版 | **¥4,980 / 节点 / 年**（标价低于整数五千，合同可写 4,980） |
| 额外节点 | 建议 ¥2,980 / 节点 / 年，避免第一档被砍到没有服务成本 |
| 试用 | 14 天全功能许可。到期前转年费 |
| 更高档 | 多节点高可用、驻场调优另议，不塞进 4,980 这一档 |

4,980 包含：1 个生产节点、专业版功能、工作日支持、规则与情报更新通道。

## 为什么这样切

社区版必须真能挡攻击，否则没有 Star，也没有试用。专业版必须锁住这些，否则开源之后没有理由付款：

- 多站点与策略模板（宽松 / 正常 / 严格）
- 威胁情报、IOC 过期、攻击 IP 自动封禁
- 地理封锁、Bot JS 挑战
- 虚拟补丁与签名规则升级
- API / 登录防护包
- Webhook 与 SIEM
- 合规映射报表、双因素、审计链
- 商用支持与可对公合同

手工改一行 IP、自己看容器日志，社区版够用。要交给运维值班和审计，就需要专业版。

## 获客路径

1. README 和 Docker 让人 5 分钟跑通，并用 XSS 请求看到 403。
2. 拦截页写明这是社区版，并指向专业版。
3. 控制台 `pro.html` 放对照表、价格和试用按钮。
4. 试用许可只从销售侧签发，私钥永远不要进这个仓库。
5. 中文内容（部署、误报、和 CRS 相处）比空仓库更容易被搜到。

早期不必追求转化率。能做到「装上的人里有一小部分来问试用」就够开始收款。

## 发布检查

- [ ] `console/config.js` 的联系方式已换成真实邮箱或表单
- [ ] 仓库里没有 `*.pem` 私钥、`*.lic`、客户配置
- [ ] `docker compose up -d` 后，正常请求 200，XSS / sqlmap 为 403
- [ ] README 没有写「已通过等保」
