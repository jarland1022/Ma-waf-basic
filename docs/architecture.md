# Ma-WAF 架构设计文档

## 1. 产品定位

Ma-WAF 是一套**独立部署的企业级 Web 应用防火墙**，基于 Nginx + ModSecurity 3.x 深度集成，叠加管理平面、规则引擎、审计与运维能力，可在客户侧物理机/虚拟机/云主机独立运行，不依赖外部 SaaS 运维平台。

## 3. 分层说明

| 层级 | 技术 | 职责 |
|------|------|------|
| 数据平面 | Nginx + ModSecurity + (可选) Lua | 流量检测、拦截、限速、Geo、协议合规 |
| 控制平面 | Go API 服务 | 规则/站点/例外/License、模式切换、健康检查、指标、回滚 |
| 展示平面 | Vanilla 控制台（React 可选） | 攻击态势、规则、站点、例外、License、合规参考 |
| 运维平面 | Bash + Python 3.9 | 部署、CRS、加固、完整性校验、威胁情报、告警 |
| 系统平面 | Rocky/openEuler + systemd | HA、重启、资源限制、内核加固 |

## 4. 关键设计决策

### 4.1 规则热加载

ModSecurity 本身不支持完整规则集无重启热更。企业级实现采用：

1. **Nginx `-s reload`**：配置/`include` 变更后优雅重载（推荐主路径）
2. **规则文件分片 + include**：按功能拆分 `custom/*.conf`，减小 reload 影响面
3. **双缓冲配置目录**：`active` / `staging`，校验通过后原子切换 + reload
4. **失败自动回滚**：reload 失败则恢复上一版本并再次 reload

> 说明：真正的「零 reload」仅适用于部分动态数据（IP 黑名单等可通过外部 lookup / Lua 共享字典实现）。CRS 全量规则变更必须经 nginx reload。

### 4.2 Fail-Open / Fail-Closed

| 模式 | 行为 | 适用场景 |
|------|------|----------|
| fail-closed | 引擎异常时拒绝流量 | 高安全等级 |
| fail-open | 引擎异常时放行 | 可用性优先（默认企业交付可配置） |
| DetectionOnly | 只记日志不拦截 | 上线磨合期 |

通过 `SecRuleEngine` + systemd `Restart=` + 健康检查联动实现。

### 4.3 审计防篡改

每条审计事件计算：

```
hash_n = SHA256(hash_{n-1} || event_payload || timestamp)
```

哈希链写入独立只追加日志，配合 `chattr +a` 与定期完整性校验。

### 4.4 管理面隔离

- 管理 API 仅监听 `127.0.0.1` 或独立管理网卡
- Nginx 管理 vhost 做源 IP 白名单
- JWT + TOTP 双因素；登录失败限速
- 与数据平面进程用户分离（`waf-mgr` vs `nginx`）

## 5. 目录约定（生产）

```
/usr/local/nginx/                 # Nginx + 模块
/usr/local/nginx/conf/modsecurity/
/usr/local/ma-waf/                # 产品根（本仓库安装目标）
  ├── bin/                        # 管理 API、工具
  ├── conf/                       # 产品配置
  ├── rules/                      # 规则 active/staging
  ├── var/{log,run,lib}/
  └── backups/
/data/logs/nginx/                 # 访问/审计日志
```

## 6. 数据流

1. 客户端请求 → Nginx（TLS/协议合规）
2. → limit_req/limit_conn/GeoIP 前置过滤
3. → ModSecurity（规范化 + CRS + 自定义）
4. → 放行则反代后端；拦截则返回定制错误页（含 Request-ID）
5. 审计 JSON → 日志管道 → 哈希链 / 轮转 / 可选 SIEM 外发
6. 管理 API 读取指标与日志索引，供控制台展示

## 7. 扩展点

- **威胁情报**：定时拉取 IP/域名 IOC，写入 `ipdeny` map 或 Redis
- **虚拟补丁**：CVE 关联规则文件，带 `expire_at` 元数据，过期自动禁用
- **API 安全**：OpenAPI 规范入库，Lua/Go 侧做路径/方法/参数校验
- **合规报表**：按等保/ISO/GDPR 控制项映射审计事件生成 PDF/CSV
