Open source WAF

把站点放到防火墙后面，几分钟就能拦截常见 Web 攻击。

Ma-WAF Community 是基于 Nginx、ModSecurity 与 OWASP CRS 的自托管反向代理。社区版永久免费；生产多站点、情报联动与商用支持在专业版。

申请 14 天专业版试用 查看专业版与价格 打开防护演示站

1. 启动

仓库根目录执行 docker compose up -d。本控制台默认 :8090，防护入口见 .env 中的 WAF_HTTP_PORT。

2. 验证拦截

打开演示站，点击 XSS / SQL 注入测试。引擎为 On 时应返回 403，并看到 Ma-WAF 拦截页。

3. 接到你的业务

修改 docker-compose.yml 的 BACKEND。上线初期可把 MODSEC_RULE_ENGINE 设为 DetectionOnly。

社区版已经包含

OWASP CRS

SQL 注入、XSS、命令注入、路径遍历等常见 Web 攻击检测与拦截。

扫描器封禁

拦截 sqlmap、nikto、acunetix 等已知扫描器 User-Agent。

基础限速

按源 IP 限制请求速率，减轻简单的应用层刷接口。
