Self-host install

自己安装社区版，马上形成防护。

只需 Docker。安装后流量经 WAF 再到你的网站；控制台可看拦截事件并维护 IP 黑名单。

1. 安装

Windows

powershell -File scripts\install.ps1

Linux / macOS

sh scripts/install.sh

或手动：复制 .env.example 为 .env，确保 logs/modsec_audit.log 是文件，再 docker compose up -d。

2. 验证效果

  1. 打开控制台登录（默认 admin / admin）。
  2. 点「一键验证防护效果」，应看到 XSS / SQLi / 扫描器用例返回 403。
  3. 下方「最近拦截」表格应出现审计事件。
  4. 也可运行 scripts/smoke-test.ps1 / smoke-test.sh。

3. 保护真实业务

编辑 .env：

BACKEND=http://你的应用主机:端口

WAF_PUBLIC_URL=http://服务器IP:8080

然后 docker compose up -d。把域名 / 负载均衡指到 WAF 端口，而不是直连应用。

上线初期可设 MODSEC_RULE_ENGINE=DetectionOnly 只观察不拦截，确认误报后再改回 On。

社区版边界

包含：CRS、扫描器 UA、限速、IP 黑名单、事件总览。

不含：多站点控制台、威胁情报、地理封锁、SIEM、合规报表、虚拟补丁升级——见 专业版。
