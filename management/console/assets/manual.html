Ma-WAF 用户手册

本手册说明管理控制台（默认 https://<IP>:8443/）的主要功能与日常操作。数据面基于 Nginx + ModSecurity + OWASP CRS。

2. 登录与安全

  • 默认管理入口：https://<设备IP>:8443/（自签证书需浏览器信任或继续访问）。
  • 默认账号：admin（生产环境请修改密码并启用 TOTP / bcrypt）。
  • 管理面默认仅允许本机与私网访问（见 Nginx allow 列表）。

4. 站点管理

Web 站点

创建/编辑反向代理站点：域名、监听端口、上游、是否启用 WAF、限流、JS Challenge、Geo、API 前缀等。保存后会触发 Nginx 配置检测与 reload。

站点自发现

从访问日志解析 Host，对照已纳管站点；可将未防护域名一键创建站点草稿。

5. 策略与规则

  • 安全策略：预置 loose / normal / strict / debug / emergency 等画像，可套用到站点。
  • 防护规则：查看/启停自定义规则、虚拟补丁、规则包。
  • 规则例外：对误报 URL/规则做放行。
  • 重保模式：一键拉高 CRS 偏执级别并确保引擎 On（需填写原因写入审计）。
  • 引擎模式：On（拦截）/ DetectionOnly（仅检测）/ Off。

6. 监控与报表

  • 安全事件：展示 Host、状态码、请求/响应长度、攻击字段；支持「详情」查看规则命中与 POST body 预览。
  • 报表：攻击趋势、Top IP/规则，可导出 CSV / 合规 HTML。

7. 对象

  • 地址簿：可复用 IP/网段对象，可应用到黑/白名单。
  • IP / Geo 名单：黑白名单与国家封锁（需 GeoIP MMDB 与模块）。

8. 系统运维

  • 系统与特征库：主机信息、CRS/Geo/情报状态；页面内可本地升级规则库。
  • PKI：生成管理面 admin.crt / admin.key。
  • 系统运维：主机指标、HA 状态、告警 Webhook、自动加黑等。
  • 故障排查：一键体检（nginx -t、证书、控制台文件、端口、磁盘等），可修复证书 / Reload，并查看 error 日志尾部与常见问题速查。
  • 许可证：指纹与 .lic 导入。

9. 规则库本地升级

路径：系统 → 系统与特征库 或 系统 → 特征库升级。

  1. 准备 .tgz / .tar.gz，建议包含 custom/*.conf 和/或 rules/*.conf。
  2. 可选上传同名 .sig（配合 conf/update-pubkey.pem）。
  3. 勾选「立即 promote 并 reload」后点击升级。
sudo ./scripts/update_rules.sh --offline /path/to/rules_bundle.tgz

10. 常用运维命令

# 功能可用性验证
sudo ./scripts/test_waf_features.sh

# 修复证书/目录/控制台
sudo ./scripts/fix_runtime.sh

# 编译安装 API
sudo ./scripts/install_api.sh

# 同步控制台静态资源
sudo ./scripts/sync_console.sh

# Nginx 检测与重载
sudo /usr/local/nginx/sbin/nginx -t && sudo /usr/local/nginx/sbin/nginx -s reload

11. 常见问题

控制台打不开 / nginx -t 报缺证书

到 系统 → PKI 生成证书，或执行 fix_runtime.sh，再 nginx -s reload。

数据面返回 502

WAF/Nginx 入口正常，但 upstream 业务未启动。请检查站点上游地址与后端进程。

攻击探针未拦截

确认 SecRuleEngine 为 On（DetectionOnly 只记审计不拦截），且站点启用了 ModSecurity。

界面改了不生效

同步 management/console → share/console 后强制刷新（Ctrl+F5）。
